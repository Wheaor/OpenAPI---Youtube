# Bounded Contexts 5: Monetización del Ecosistema Creador

description: |
  ### Contexto de Dominio 5: Monetización del Ecosistema Creador
  Responsable de la gestión financiera y contable de los creadores de contenido (RF-M1 a RF-M5). 
  Este servicio se encarga de:
  * Evaluar y controlar los requisitos de elegibilidad de los canales para optar al programa de socios (RF-M1).
  * Configurar y registrar los productos de apoyo directo del espectador como membresías y propinas (RF-M2).
  * Capturar flujos de ingresos brutos y aplicar las reglas de reparto de ganancias (Revenue Share) (RF-M3).
  * Exponer tableros de analítica financiera desglosada por periodos y contenidos (RPM) (RF-M4).
  * Administrar los saldos acumulados, la retención de impuestos fiscales y procesar las solicitudes de pago (Payouts) (RF-M5)
